# 常用命令

| 命令 | 功能 |
| --- | --- |
| `/menu` 或蹲下 + F | 打开快捷菜单，可进入传送、钱包、邮箱、商店和配方查询等功能 |
| `/tpa <玩家>` | 请求传送到在线玩家身边；对方可点击聊天消息或使用 `/tpaccept` 接受，请求 3 分钟后过期 |
| `/tpahere <玩家>` | 邀请在线玩家传送到自己身边 |
| `/tpaccept` | 接受传送请求 |
| `/sethome`、`/home` | 设置一个家并返回家 |
| `/back` | 返回上一个记录的位置 |
| `/rtp` | 在当前世界随机传送；大厅不可用，冷却 30 秒。下界和末地地形危险，谨慎使用 |
| `/money` 或 `/money money` | 查询账户余额 |
| `/money top` | 查看货币排行榜 |
| `/money pay <玩家> <金额>` | 向在线玩家转账，金额大于零，最多两位小数 |
| `/money save` | 将主手中的支持的水晶货币存入账户 |
| `/money drop` | 取出最多 64 个水晶币；背包无空位时掉落在地上 |
| `/signin` | 手动签到或查看本次签到结果 |
| `/mail` | 打开邮箱 |
| `/mail send <玩家名>` | 将主手整组物品发给指定玩家，支持离线收件 |
| `/shop`、`/recipe` | 打开建筑商店、配方查询器 |
| `/item` | 在聊天中展示主手物品 |

实际命令以服务器运行的插件版本和权限配置为准。
