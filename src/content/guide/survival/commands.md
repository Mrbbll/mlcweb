# 主要命令

| 命令 | 说明 |
| --- | --- |
| `/tpa 玩家` | 请求传送玩家，已添加聊天框点 id 传送 |
| `/tpahere 玩家` | 请求目标玩家传至你当前位置 |
| `/sethome` | 设置家，仅能设置一个且不加名字 |
| `/home` | 回家 |
| `/spark ..` | 服务器资源信息 |
| `/tpsbar` | 显示 tpsbar |
| `/menu` 或蹲下 + F | 打开服务器菜单 |
| ~~`/fp`~~ | ~~假人有关命令~~ |
| `/mail` | 打开邮箱 |
| `/rtp` | 在当前维度随机传送，不要在末地和地狱用此命令 |
