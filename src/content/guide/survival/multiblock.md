# 多方块结构

## 附魔增强与等级上限

通过多方块结构可以提升下列附魔，物品和附魔书超过上限时会被限制到对应等级：

| 附魔 | 最高等级 |
| --- | --- |
| 锋利 | VII（7） |
| 效率 | VII（7） |
| 耐久 | V（5） |
| 保护 | VI（6） |
| 时运 | V（5） |
| 快速装填 | V（5） |
| 力量 | VII（7） |
| 连锁挖掘 | V（5） |

其他附魔使用原版上限，不能通过此结构提升。连锁挖掘可在附魔台或村民交易中获得，适用于镐、锹、斧和锄；不蹲下挖掘时会连带破坏相连的同种方块，每级最多 8 个（包括起始方块），消耗工具耐久。蹲下可暂停连锁；受领地保护限制的方块不会被连锁破坏。

抢夺每级额外增加 25% 的生物经验掉落；手持精准采集工具且没有蹲下时，可瞬间破坏玻璃及玻璃板。

### 搭建和使用

![突破附魔上限多方块结构](pics/guide/survival/multiblock-1.jpg)

以幽匿尖啸体为中心：正下方放哭泣的黑曜石，再下一层放 3×3 下界合金块；该层四角外侧各放一个幽匿催发体。在尖啸体下一层的东、南、西、北四个方向距离中心两格处，各放一个**充满四格能量的重生锚**。其他位置无需清空。

![附魔物品摆放次序](pics/guide/survival/multiblock-2.png)

快捷栏第 1 格放一个下界之星并手持，第 2 格放目标物品，第 3、4 格放完全相同的两本附魔书。右键尖啸体后，消耗下界之星和两本书，约 3 秒后掉出强化后的物品；四个重生锚会变回未充能状态。

附魔书必须非空，所含附魔都须在上表中、适用于目标物品，且不能与物品已有附魔冲突。两本书每种附魔先按书上等级加 1 合并到物品：如果物品上同一种附魔恰好等于这个等级，则再加 1；如果物品已有等级更高，则保留原等级。书的等级不能比物品已有等级低两级以上，结果也不能超过上表的上限。

例如，两本效率 V 书与无效率的镐可得到效率 VI；与已有效率 VI 的镐合并可得到效率 VII。请先确认快捷栏中只有准备消耗的物品。

## 传送石碑

如图搭建。

![传送石碑搭建](pics/guide/survival/multiblock-3.jpg)

磁石上放灵魂灯笼是私人传送石碑，放信标是公共传送石碑，右键灯笼或者信标即可打开菜单。

想要命名石碑，只需要拿一个物品放入铁砧重命名，并且再蹲下右键灯笼或者信标即可。

私人石碑仅所有者和 OP 可在列表中使用；公共石碑对玩家开放。石碑所有者或 OP 可修改图标和拆除。目的地上方空间不足时无法传送。公共石碑可在 BlueMap 上显示。
